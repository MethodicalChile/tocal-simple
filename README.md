# Tocal Web

Sitio corporativo estático desarrollado con Vue 3 + Vite.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar producción

```bash
npm run build
```

El resultado queda en `dist/`.

## Contenido editable

La mayoría del contenido se encuentra en:

`src/data/site.js`

Desde ahí se pueden modificar:
- Datos de empresa
- Servicios
- Proyectos
- Indicadores

## Imágenes

Actualmente la maqueta usa imágenes remotas de Unsplash como placeholders.
Antes de producción se recomienda reemplazarlas por fotografías propias de Tocal y guardarlas en `public/images/`.
